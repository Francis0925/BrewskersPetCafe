# Code of Conduct

This repository is a school project, but people do read it, fork it and open issues, so here is how we would like things to go.

## The short version

Be decent. Assume the other person is trying to help. Disagree about the code, not about the person.

## What we expect

- Be polite in issues, pull requests, comments and commit messages, even when you think something is wrong.
- Give feedback you would be happy to receive: say what is wrong, say why, and suggest a fix if you have one.
- Remember that some of us are still learning. A "this could be simpler, here is how" helps more than a sarcastic comment.
- Credit other people's work. If you copy code or an idea, say where it came from.
- Keep other people's private information private. That includes real customer, staff or pet owner data that might end up in a database file or screenshot.

## What is not okay

- Insults, name calling, or personal attacks.
- Harassment of any kind, including unwanted messages, following someone around the repository, or repeated pestering after being asked to stop.
- Discrimination or jokes aimed at someone's gender, race, religion, disability, age, nationality, sexuality or background.
- Sexual or violent content, or threats.
- Posting someone's personal information without their permission.
- Spam, or using the issue tracker for advertising.

## Who this covers

Everyone who takes part here: the group members, classmates, teachers, and anyone who opens an issue or pull request. It applies in this repository and in any space where you are speaking for the project.

## If something goes wrong

Tell the repository owner (Francis0925 on GitHub). You can use a private message, or the private reporting option on the Security tab if you would rather not post publicly. Include a link or screenshot if you can. We will read it, keep your report between the people who need to see it, and will not punish anyone for reporting in good faith.

If someone breaks these rules, we may do any of the following, depending on how serious it is:

1. Ask them to stop and explain why.
2. Remove the comment, issue or pull request.
3. Block them from the repository.

If a report involves one of the group members, it goes to the course instructor instead.

## Where this came from

We wrote this ourselves in plain language, after reading a few well-known codes of conduct. It is not meant to be complicated. If something here is unclear or unfair, open an issue and tell us.
